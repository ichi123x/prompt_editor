# レビュー記録 索引

コードレビュー・設計レビューの記録を時系列で残す。

- 命名規則：`YYYY-MM-DD-対象.md`
- 各記録は「対象／日付／レビュアー／総評／重要度別の指摘（🔴高 🟡中 🟢低）／推奨アクション／ステータス」で構成する
- 指摘の対応状況は各ファイル内の `[ ] → [x]` で追跡する
