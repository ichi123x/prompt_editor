# decisions.md — 設計判断の記録（ADR）

> **用途**：「なぜこの設計にしたか」を記録する。
> 後から見返したとき・Claudeが判断に迷ったときの根拠として参照する。

---

## 記録フォーマット

```
## ADR-XXX: タイトル
- **日付**：YYYY-MM-DD
- **状態**：提案中 / 採用 / 却下 / 廃止
- **背景**：なぜこの判断が必要だったか
- **決定内容**：何を選んだか
- **却下した選択肢**：何を選ばなかったか・理由
- **影響**：この決定による制約・副作用
```
