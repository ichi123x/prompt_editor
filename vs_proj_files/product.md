# product.md — プロダクト要件定義

## ゴール

スペック駆動開発に必要なMarkdownファイル群（CLAUDE.md / product.md / structure.md / decisions.md / tasklist.md）を、GUIから入力して一括生成できるツールを作る。
プラットフォーム（WinForms / WPF / MFC / Win32 / Web）をラジオボタンで選択することで、技術スタック欄が自動補完される。

## ターゲットユーザー

- 一郎さん本人（フリーランス組み込みエンジニア）
- Claude Codeを使ったスペック駆動開発を始める際に毎回使う

## 解決したい課題

- 新規プロジェクト開始時に毎回 `.steering/` や `tasks/` のmdファイルを手書きするのが手間
- プラットフォームによって structure.md の技術スタック欄が変わる→自動化したい
- Claudeへの指示（CLAUDE.md）の書き忘れを防ぎたい

## 成功の定義（完了条件）

- [ ] ダイアログを開いてプロジェクト名・目的・担当者を入力できる
- [ ] プラットフォームをラジオボタンで選択できる（5種類）
- [ ] タブ別（要件定義／設計／タスク管理／CLAUDE.md）で内容を入力できる
- [ ] 「生成」ボタンで指定フォルダに md ファイル一式が出力される
- [ ] 出力ファイルが既存テンプレートの書式と一致する

---

## スコープ

### In Scope（対象）
- CLAUDE.md / product.md / structure.md / decisions.md / tasklist.md の生成
- プラットフォーム選択による技術スタック自動補完
- 出力先フォルダのブラウズ選択
- 入力内容の簡易バリデーション（必須項目チェック）

### Out of Scope（対象外）
- Markdown のプレビュー表示
- Git 操作（コミット・プッシュ）
- Claude API との連携
